# Overview

fR3Z0 is a stereo resonator. Input (and optional noise) feeds eight bandpass voices. They ring according to decay and intensity, get panned and mixed with the dry signal, then soft-clipped.

MIDI note-on sets the global root. Pitch bend is ±2 semitones. Freeze stops new input so the bank can ring out. Kill zeros the filter state.

The graph and the knobs write the same APVTS parameters. Hosts can automate every one of them.
